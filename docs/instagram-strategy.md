# 인스타그램 전략 — @pro_konwoo

## 결정 (2026-10-12, 서프로님 확정 — 같은 날 B안으로 변경)

**콘셉트: "양재역 라인 빌딩 + AI"**

처음엔 "AI 쓰는 도곡동 중개사"(주거·동네)로 정했으나, 서프로님이 요즘 주거 파밍은 거의 안 하고
**양재역 가는 라인의 빌딩** 위주로 파밍 조사 중이라 B안으로 바꿨다.

인스타의 역할: 팔로워 수보다 **파밍 때 만난 건물주·매수자가 계정을 찾아봤을 때
"이 사람은 이 라인 빌딩을 잘 안다"는 믿음을 주는 포트폴리오**.

| 주 | 올리는 것 | 서프로님 할 일 | Claude 할 일 |
|---|---|---|---|
| 홀수 주 | 양재역 가는 길의 건물·거리 10초 영상 (1층 상가 변화, 공사 현장, 임대 현수막 등) | 지나가다 10초 찍기 → 맥 다운로드 폴더로 에어드롭 | 자막·글·해시태그·올릴 시간 |
| 짝수 주 | AI로 건물 정보 정리하는 화면 (건축물대장·토지 정보 요약 등) | 화면 녹화 1번 → 같은 방법으로 넘기기 | 자막·글·해시태그·올릴 시간 |

소개 문구 (초안, 서프로님이 직접 붙여넣음):
```
양재역 라인 빌딩 전문 공인중개사
AI로 건물을 분석합니다
거리 관찰 · 빌딩 데이터 기록
📩 매각·매입 상담 DM
```

지킬 것:
- 바둑 콘텐츠는 하지 않는다(서프로님: "바둑은 안 해도 괜찮다")
- 판단·전망은 서프로님이 직접 쓴 말만 넣는다. Claude 는 사실만 쓴다(스레드와 같은 규칙)
- **매물인 특정 건물은 올리지 않는다.** 올릴 때는 중개대상물 표시·광고 규정을 지키고,
  건물주 동의 없이 매물임을 드러내지 않는다. 기본은 거리 풍경·동네 변화
- **보류**: 소개 문구에 알파고 심판 한 줄 / 댓글→DM 자동 답장
- 스레드 자동 글도 10-12에 빌딩으로 바꿨다(진행상황.md 8번)
- **업로드 때 'Threads에 공유'는 기본으로 끈다**(10-22). 스레드에 없는 사진 게시물일 때만 켠다(해시태그 빼고)

### 계정 방향 (2026-10-12, 서프로님 확정: B)

새 계정을 만들지 않고 **지금 계정(@pro_konwoo)을 정리해서 키운다.**
- 이유: 서프로님 시간이 병목(계정 2개는 일이 두 배), 건물주에게 믿음을 주려면 이력 있는 계정이 낫다
