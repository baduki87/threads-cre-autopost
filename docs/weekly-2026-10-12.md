## 6. 발견한 문제 3가지

1. **발행 시간이 크게 밀린다.** GitHub 무료 실행이 늦게 돌면서 실제 발행 시각이
   - 08시 글 → 10시~12시 반
   - 17시 글 → **밤 9시 ~ 새벽 3시**
   - 21시 글 → **새벽 0시 반 ~ 오전 6시**
   로 밀렸다. 특히 17시 질문 글이 새벽에 올라가면 댓글이 붙을 시간을 잃는다.
   → **예약 시각을 3~4시간 앞당기면** 원래 노린 시간대에 가깝게 떨어진다(서프로님 결정 필요).
2. **아파트 글이 하나 섞였다.** 질문 "리모델링 고민"이 "오래된 아파트 리모델링"으로 나왔다. 주제 설명에 '건물'을 못 박지 않아서다. → 주제 설명을 고치면 된다.
3. **2편 연재가 효과가 없다.** 방법론은 1편·2편으로 나눠 내는데, 2편이 1편보다 나은 경우가 없었고 같은 제목이 이틀 연속 나가 지루해 보인다. → 연재를 끄고 매일 새 주제로 바꾸는 것을 검토.
