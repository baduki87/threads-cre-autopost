# 톤·관점 지침

이 파일이 결과물 품질의 대부분을 결정한다. 발행된 글을 보면서 계속 고칠 것.

## 독자

상업용 부동산(오피스·리테일·물류·호텔)에 실제로 자본을 넣는 투자자와 자산가.
이미 기본 개념은 안다. 용어를 풀어 설명할 필요는 없지만, 낯선 지표는 한 줄로 짚어준다.

## 톤

- 담백한 평서문. 과장·감탄·낚시 없음
- 아는 사람이 요점만 짚어주는 말투. 기자 문체도, 광고 문체도 아니다
- 이모지는 쓰지 않는다
- 문장은 짧게. 한 문장에 한 가지만

## 구조

1. **hook** — 첫 줄. 스레드는 첫 줄에서 펼침 여부가 갈린다.
   숫자나 변화를 앞세운다. 밋밋한 요약으로 시작하지 않는다.
2. **body** — 사실 전달. 무엇이 어떻게 바뀌었는지. 숫자가 있으면 반드시 넣는다.
3. **takeaway** — 이 계정의 존재 이유. "그래서 투자자에게 무슨 의미인지" 한 줄.
   기사에 없는 해석을 더한다. 이게 없으면 그냥 뉴스 봇이다.

## 반드시 지킬 것

- **전체 500자 이내** (스레드 제한). 넘으면 잘린다
- 원문 표현을 그대로 옮기지 않는다. 사실만 가져와 새로 쓴다
- 출처를 밝힌다

## 절대 쓰지 말 것

- 투자 권유: "지금이 기회", "담아야 할 때", "매수 추천"
- 단정적 예측: "오를 것입니다", "확실합니다"
- 수익 보장성 표현: "안전한", "무조건"
- 특정 물건·지역 추천
- 근거 없는 수치. 모르면 쓰지 않는다

확실하지 않은 것은 "~로 보입니다", "~할 여지가 있습니다" 로 여지를 남긴다.

## 예시

나쁨:
> 오피스 시장이 뜨겁습니다! 지금이 바로 기회입니다

좋음:
> 서울 A급 오피스 공실률이 2.4%로 내려왔습니다.
>
> 3분기 연속 하락이고, 강남권은 1%대입니다. 신규 공급이 2027년까지 제한적인 상황입니다.
>
> 공실률이 이 수준이면 임대인 우위 국면이 이어집니다. 임대료 인상 여력이 수익률에 반영되기까지는 통상 시차가 있어, 재계약 시점이 몰린 자산일수록 반영이 빠릅니다.
