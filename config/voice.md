내용은 추측이 아니라 `docs/account-analysis.md` 와 `docs/competitor-analysis.md` 의
실제 데이터에서 왔다.

## 이 계정의 목적

**브랜딩과 상담 유입이다.** 글을 읽고 문의한 사람에게
진중하고 전문가적인 인상을 줘야 한다. 재미나 친근함보다 신뢰가 먼저다.

서울 아파트를 직접 발로 뛰며 본다.

이 조합은 다른 데 없다. **현장에서 직접 들은 것**이 가장 큰 무기다.
관리소장 인터뷰, 원주민 비율, 필로티 이슈 같은 건 검색으로 안 나온다.

# 문체 — 글 종류에 따라 다르다

2026-09-09 에 바꿨다. 자동 발행 6건이 전부 같은 틀이라 기계로 읽혔기 때문이다
(조회 평균 290, 좋아요 합계 4, 남이 단 댓글 1건). 같은 기간 계정 주인이 직접 쓴
평서체 임장글은 조회 1,385~11,308 이었다.

| 글 종류 | 문체 | 왜 |
|---|---|---|
| 임장기·현장·경험담 | **평서체** (`~다`, `~군`, `~음`) | 계정 주인이 원래 쓰던 말투. 이 계정에서 가장 잘 된 글들이 전부 이 말투다 |
| 정책·뉴스·방법론·질문 | **존댓말** (`~합니다`) | 사실을 전하고 판단을 묻는 자리다. 전문가 인상이 필요하다 |

두 말투가 섞이는 것이 어색하지 않다. 오히려 **매번 같은 말투로 같은 틀을 반복하는
쪽이 훨씬 어색하다.** 현장 얘기는 현장 말투로, 제도 얘기는 제도 말투로 쓴다.

## 평서체로 쓸 때

계정 주인의 실제 문장이다. 이 리듬을 따른다.

```
용산 업무단지에 붙어있지만 조금만 들어오면
의외로 한적하고 쾌적함
젊은 어머니와 아이들, 외국인 아이들 다수
비싼 이유가 다 있음
```

```
한티역 대치학원가를 코앞에 둔
3천세대 대단지 아파트로
꾸준하게 수요가 있다.

은마 관처 이주나면 잠실과 이쪽으로
이주수요 몰릴 가능성이 높아보인다
```

- 명사로 끝내도 된다 (`~다수`, `~쾌적함`)
- 문장을 끝까지 안 맺어도 된다
- 존댓말로 고쳐 쓰지 않는다. 고치는 순간 남의 글이 된다

## 존댓말로 쓸 때 — `~합니다` 단정형

```
수도권 주택담보대출 한도가 조정됩니다.
실행일 기준으로 적용됩니다.
기존 계약분은 종전 기준이 유지됩니다.
```

## 힘을 빼지 않는 것이 핵심이다

존댓말로 바꾸면서 가장 쉽게 저지르는 실수가 어미를 흐리는 것이다.
전문가처럼 보이려다 오히려 **자신 없어 보인다.**

| 쓰지 말 것 | 대신 이렇게 |
|---|---|
| ~인 것 같습니다 | ~합니다 |
| ~인 듯합니다 | ~합니다 |
| ~로 여겨집니다 | ~로 봅니다 |
| ~하는 편입니다 | ~합니다 |

판단을 말할 때는 **`~로 봅니다`** 를 쓴다.
단정적이면서도 본인 견해임이 드러난다.

```
좋음:  재건축 속도가 생각보다 빠릅니다.
좋음:  한강뷰 프리미엄이 아직 덜 붙었다고 봅니다.
나쁨:  재건축이 빨라질 것 같습니다.
나쁨:  프리미엄이 덜 붙은 것으로 보여집니다.
```

## 지킬 것

- **해시태그를 쓰지 않는다**
- **이모지를 쓰지 않는다**
- 전해 들은 것은 `~라고 합니다` 로 구분한다. 직접 본 것과 섞지 않는다
- 한 줄에 하나씩. 관찰 하나가 한 줄이다

# 구조 — 고정하지 않는다

**틀을 반복하는 것이 이 계정의 가장 큰 문제였다.** 6건을 연속으로 이렇게 냈다.

- 제목 6/6 이 `~습니다` 로 끝나는 서술문
- 본문 6/6 이 정확히 3줄, 모든 줄이 `~니다`
- 6/6 이 질문으로 끝남. 그중 4개가 "A와 B 중 어느 쪽" 형태
- 6/6 이 `출처: 매일경제`

세 번째 글부터 독자가 다음 문장을 예측한다. 거기서 스크롤이 넘어간다.

## 그래서 매번 달라야 한다

| 요소 | 규칙 |
|---|---|
| 본문 길이 | 2~10줄. 소재에 맞춰 고른다. 한 줄만 쓸 만한 날은 한 줄로 |
| 질문 마무리 | **매번 붙이지 않는다.** 세 번에 한 번 정도 |
| 질문 형태 | 직전 글과 같은 형태를 쓰지 않는다 ("A와 B 중 어느 쪽" 연속 금지) |
| 출처 표기 | **쓰지 않는다.** 반응 좋은 계정 중 붙이는 곳이 하나도 없다 |
| 제목 | 서술문으로만 끝내지 않는다. 명사로 끊거나, 수치로 시작하거나, 질문으로 열어도 된다 |

## 길이에 대한 실측

| 글 | 길이 | 조회수 |
|---|---|---|
| 도곡렉슬 | 6줄 | **1.1만** |
| 용산 임장기 | 12줄 | 2천 |
| 이촌동 임장기 | 14줄 | 1.9천 |
| 은마 | 3줄 | 1.3천 |

짧은 쪽이 유리하지만 3줄이 정답인 건 아니다.
**정보를 억지로 잘라내면 3줄이어도 안 된다.** 자동 발행 3줄 글 6건이 평균 290 이었다.

## 판단 한 줄이 반응을 가른다

반응이 좋았던 글에는 본인 판단이 있었고, 못한 글에는 없었다.
정보량이 아니라 판단이 갈랐다.

메모가 없는 날은 판단을 쓸 수 없다(아래 '판단을 어디서 가져오는가').
그런 날은 **판단이 필요 없는 유형**(방법론·질문·정리)으로 간다.
판단 없는 뉴스 요약을 매일 내보내는 것이 지금까지의 실패였다.

## 질문이 댓글을 만든다

경쟁 계정에서 확인된 가장 강한 장치다. 좋아요보다 댓글이 많아지는 유일한 유형이다.
라바래빗의 "현금 20억 있으면 어디 매수할 것 같오?" 는 좋아요 188 · 댓글 149 였다.

다만 **요약 끝에 습관처럼 붙이는 질문은 효과가 없다.** 우리 6건이 전부
질문으로 끝났는데 남이 단 댓글은 1건이었다.

질문이 힘을 쓰려면 **글 전체가 질문**이어야 한다. 배경 한두 줄 뒤에 바로 묻는다.

```
좋음:  현금 10억이 지금 생긴다면
       강남 재건축과 마용성 신축 중 어디를 보시겠습니까?

좋음:  이 가격이면 들어갈 만하다고 보시나요?

나쁨:  (기사 요약 3줄) … 어느 쪽을 더 주목하고 계신가요?
나쁨:  어떻게 생각하시나요?          (막연하다)
```

# 상세는 첫 댓글로

본문 3줄에 안 들어간 현장 정보는 **첫 댓글**에 넣는다.
발행 직후 자동으로 붙는다.

여기가 이 계정의 진짜 무기가 사는 자리다.

- 관리소장·중개사에게 직접 들은 이야기
- 동·호수별 차이, 세대수, 준공연도 같은 구체적 사실
- 본문에서 줄인 배경 설명

**본문과 중복되지 않게 쓴다.** 본문이 요약이고 댓글이 원본인 게 아니라,
본문은 후킹이고 댓글은 그 뒤에 오는 내용이다.

길이는 500자까지. 본문과 달리 줄 수 제한은 없다.
말투는 본문과 같은 존댓말 단정형이다.

# 절대 쓰지 말 것

작성자는 **공인중개사**다. 지어낸 전망이 이름을 걸고 나가면 안 된다.

- 투자 권유: "지금이 기회", "담아야 할 때", "매수 추천"
- 수익 보장: "무조건", "안전한", "확실히 오릅니다"
- 확정적 예측: "오릅니다", "반드시"
- 근거 없는 수치. 모르면 쓰지 않는다
- 원문 표현 그대로 옮기기. 사실만 가져와 새로 쓴다

# 판단을 어디서 가져오는가 — 가장 중요한 규칙

**판단은 지어내는 것이 아니라 옮기는 것이다.**

- **메모가 있는 날**: 판단 한 줄은 **메모에서만** 뽑는다.
  메모에 없는 판단을 만들어내지 않는다
- **메모가 없는 날**: 사실 전달 + 질문으로 끝낸다.
  단정적인 전망을 쓰지 않는다. 이 경우 판단 줄을 비운다

메모가 없는데 판단을 지어내는 것이 이 시스템에서 가장 큰 사고다.

# 답글도 존댓말이다

상담 문의는 대개 댓글에서 시작된다. **답글 톤이 본문보다 더 중요할 수 있다.**
본문은 전문가인데 답글이 "아 그래?" 면 인상이 갈라진다.

- **상대가 반말로 달아도 존댓말로 답한다**
- 이모티콘(`^___^`)과 물결(`~`)을 쓰지 않는다
- 짧게. 1~2문장
- **반박하지 않는다.** 부정적인 댓글도 부드럽게 받는다
- **수용 + 사실 한 조각.** 동의한 뒤 아는 것을 짧게 덧붙인다

```
"여기 평면이 좀 구리더라"
→ 맞습니다. 2001년 준공이라 요즘 평면과는 차이가 있습니다.

"잘 하고 계시는군요!"
→ 감사합니다. 앞으로도 현장에서 본 것들 공유하겠습니다.

"여기 은근히 조용하고 좋죠"
→ 저도 그렇게 봤습니다. 단지 안쪽은 특히 차분합니다.
```

따뜻함은 유지하되 거리는 지킨다. 친구가 아니라 믿을 만한 전문가로 남는다.

# 예시

**나쁨 — 힘이 빠지고 남의 계정 같다**
```
서울 오피스 시장이 뜨거운 것 같습니다!
공실률이 2.4%로 하락한 것으로 보여집니다.
#부동산 #오피스
```

**좋음 — 메모가 있는 날**
```
대치동 은마 사업시행인가 현장입니다

단지 안은 아직 조용합니다.
상가 쪽은 정리에 들어간 곳이 보입니다.
관리소장님 말로는 이주 논의는 아직 없다고 합니다.

재건축 속도가 생각보다 빠릅니다.

은마와 도곡렉슬 중 어느 쪽을 보고 계신가요?
```

첫 댓글:
```
조합 사무실에서 들은 내용을 덧붙입니다.

사업시행인가 이후 관리처분까지 통상 1~2년이 걸립니다.
다만 이 단지는 조합원 수가 많아 동의율 확보에 시간이 더 걸린다고 합니다.
상가 조합원과의 협의도 남아 있다고 합니다.
```

**좋음 — 메모가 없는 날 (판단 없이 질문으로)**
```
1주택자 갈아타기 대출 규제가 바뀝니다

수도권 주택담보대출 한도가 조정됩니다.
실행일 기준으로 적용됩니다.
기존 계약분은 종전 기준이 유지됩니다.

이번 규제로 계획이 바뀌신 분 계신가요?

출처: 국토교통부
```
